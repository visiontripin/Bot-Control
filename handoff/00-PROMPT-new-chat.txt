ПРОМТ ДЛЯ НОВОГО ЧАТА — BotControl (скопируй всё ниже линии и вставь первым сообщением)
==========================================================================================

Продолжаем проект BotControl: Android-приложение на Kotlin и Jetpack Compose
(пакет com.botcontrol.admin) + локальный веб-редактор и сборка для Windows
(tg-bot-control/desktop-web → BotControl.exe). Android-приложение превращает
телефон в хост локальных Telegram-ботов: long polling Bot API, несколько ботов
на разных токенах, правила и конструктор клавиатуры/кнопок, анимации правкой
сообщения, фото-анимации, расписание и посты в канал, режим «Объявления»,
импорт и экспорт конфигов ботов «кодом» (python-подобный текст, который НЕ
исполняется), автозапуск после перезагрузки, LLM строго на устройстве.

ПЕРВЫЕ ДЕЙСТВИЯ (по порядку):
1. Подтяни проект в свою ветку сессии (у нового чата будет своя ветка arena/…):
     git fetch origin main
     git merge --ff-only FETCH_HEAD   # или: git reset --hard origin/main,
                                      # если в твоей ветке только «Initial commit»
   Проверь: git log --oneline -3.
   Удобная ссылка: ln -sfn "$PWD/tg-bot-control" /home/user/tg-bot-control
2. Прочитай ЦЕЛИКОМ:
     handoff/01-project-rules.txt     — мои строгие требования (соблюдать всегда)
     handoff/02-build-release.txt     — сборка APK в GitHub Actions, проверка, ссылки
     handoff/03-sandbox-traps.txt     — ловушки песочницы и кода (что уже ломалось)
     handoff/04-state-and-backlog.txt — текущее состояние, карта файлов, открытые задачи
     tg-bot-control/ПЕРЕДАЧА-КОНТЕКСТА.md — полная память проекта (грамматика импорта,
                                          история версий, ловушки)
3. Проверь, что CI сработает на твоей ветке: в .github/workflows/*.yml
   стоит branches: ["arena/**", "main"]. Сборка APK запускается пушем в ветку,
   тег и релиз создаются, когда в сообщении коммита есть [apk].

ЧТО УЖЕ СДЕЛАНО (v1.6.3–v2.2.0 + desktop-web 0.7.0, этапы 1–5):
  • Этап 1 (v1.8.0): 3-уровневые inline-подменю, regex, HTML/MarkdownV2, опросы, медиа, copy_text/web_app, ShuffleBag и jitter;
  • Этап 2 (v1.9.0): JS + SQLite Room db, анкеты FSM, CRM подписчиков, роли, рассылки и разовые даты;
  • Этап 3 (v2.0.0): группы/форумы, кнопка-капча, антиспам/антифлуд, авто-заявки, реакции и локальный Webhook;
  • Этап 4 (v2.1.0): Inline @бот, оплаты Telegram Stars (XTR), Mini Apps (/miniapp), http.get/post и входящие медиа;
  • Этап 5 (v2.2.0 + desktop-web 0.7.0): паритет Windows (.bc на диске с 10 бэкапами, мультибот, полный .py ↔ .bc),
    HTTPS-only (network_security_config), 6-значный PIN Wi-Fi сервера (:8090), watchdog Rhino 2 с, 🩺 Диагностика;
  • готовые конфиги *-ready.py: showcase-all-ready.py (демо всех фич) и обновлённый presentation-bot-ready.py (@AppBotcontrol_bot);
  • репозиторий, релизы, verify-release.sh, shared-telegram-mock и сайт сведены в main.
